# Components

One line per component: `- [name](name/README.md) — purpose`. Copy `_template/` to add a new one. A live demo of all components is in `../examples/demo.html`. Springs demo (draggable sheet + CSS-spring switch): `../examples/springs.html`, built on `../lib/spring.js`.

- [button](button/README.md) — the one pressable control: primary / subtle / ghost, optional pill, soft press
- [composer](composer/README.md) — ChatGPT-style growing input with an attach/send bar
- [segmented](segmented/README.md) — pill mode switcher with Craft's clip-path thumb
